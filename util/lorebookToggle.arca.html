**-- Hero --**

RISUAI PLUGIN · API 3.0
📕 로어북 토글
로어북을 지우지도, 키를 건드리지도 않고 껐다 켠다.
이번 턴만 빼거나, 삽화·요약 같은 보조모델 요청에서만 빼는 것도 된다.
ON OFF 1턴 OFF 보조 제외

**-- Why --**

이런 분한테
로어북이 100개 넘는데 특정 장면에서만 몇 개 빼고 싶을 때. 삭제하거나 키 지웠다가 다시 넣는 건 너무 귀찮다.
삽화 모듈이 보조모델로 이미지 프롬프트를 뽑는데, 세계관 로어북이 통째로 따라 들어가서 토큰만 축낼 때.
"이 턴만 로어북 없이 어떻게 나오나" 테스트해보고 싶을 때.

**-- Two axes --**

상태는 두 축으로 따로 논다
항목마다 메인 상태와 보조 상태가 각각 있고, 서로 건드리지 않는다.
① 메인 축 — 로어북 엔진에 작용
ON평소대로 들어간다.
OFF고정 끄기. 다시 켤 때까지 꺼진다.
1턴 OFF이번 턴만 끄기. 다음 요청 하나(채팅이든 삽화든)가 빠진 채 나간 뒤 자동으로 켜진다.
② 보조 축 — 보조모델 요청에만 작용
보조 제외메인 채팅엔 그대로 들어가고, 삽화·요약·루아 axLLM 같은 보조모델 요청에서만 빠진다. 한 번 설정하면 계속 유지.
보조 포함기본값. 보조 요청에도 들어간다.
예: 보조 제외 깔아둔 항목에 1턴 OFF를 걸면, 그 턴만 메인에서도 빠지고 복구되면 다시 "메인 ON · 보조 제외"로 돌아온다.

**-- How it works --**

어떻게 끄는 건데?
리수 로어북 엔진은 항목 내용 맨 위에 @@dont_activate 데코레이터가 있으면 키 매칭이든 상시활성이든 상관없이 그 항목을 안 넣는다. 이 플러그인은 그 한 줄을 끼웠다 뺐다 하는 게 전부다.
@@dont_activate lbtoggle        ← 고정 끄기
@@dont_activate lbtoggle once  ← 이번 턴만
@@lbtoggle sub_off              ← 보조 제외
레나 라이온즈는 {{char}}가 소속된 프로야구 구단이다. ...
· 키, 보조키, 삽입 순서, 상시활성, 폴더 전부 원본 그대로
· 상태가 항목 내용 안에 있어서 별도 저장소 없이 세이브와 같이 동기화
· 플러그인을 지워도 마커 줄만 남을 뿐이고, 그 줄은 엔진이 그냥 무시한다
· 보조 제외는 요청이 나가기 직전 훅에서 그 항목 문장을 메시지에서 걷어내는 방식 (DB엔 아무것도 안 씀)

**-- Install --**

설치
1아래 파일을 받는다 (lorebookToggle.plugin.js)
2리수 → 설정 → 플러그인 → 플러그인 불러오기
3권한 물어보면 허용. 요청 수정(보조 제외·자동 복구용), 데이터베이스(모듈 로어북 읽기용), 메인 화면(버튼 색 바꾸기용) 세 가지
4채팅 화면 오른쪽 위 📕 버튼으로 연다
버전을 올려 다시 넣으면 리수가 새 스크립트로 보고 권한을 다시 묻는다. 요청 수정 권한은 리수가 3일마다 한 번 더 확인하는데, 거부하면 보조 제외랑 자동 복구가 조용히 꺼지니 허용으로.

모드 선택

모두 / 캐릭터 / 모듈 전체 / 그룹 / 개별범위별 일괄 버튼. 검색창에 이름이나 키를 치면 보이는 것만 일괄 적용된다.
비활성 모듈 안 보기꺼진 모듈 로어북은 어차피 안 들어가니 숨긴다. 기본 켬.
최근 요청 기록요청이 지나갈 때마다 한 줄. 메인/보조 구분, 메시지 수, 걷어낸 항목(✂️ 통째 / ✂️△ 일부), 글자 수 변화, 응답 길이. 크게 보기로 펼칠 수 있다.
편집 전 / 삭제된 부분만 / 편집 후보조 제외가 실제로 걷어낸 요청은 본문을 최근 2개까지 메모리에 들고 있다. 빨간 취소선으로 뭐가 빠졌는지 보고, JSON으로 복사도 된다. 새로고침하면 사라진다.

**-- Recipes --**

자주 쓰는 조합
삽화 모듈에 로어북 안 넣기
모드를 보조모델 제외로 → 캐릭터 "보조 제외" 한 번. 끝. 메인 채팅은 그대로고 삽화 요청만 가벼워진다. 실제로 17만 자짜리 삽화 요청이 7만 자로 줄었다.
이 턴만 세계관 빼고 받아보기
모드를 이번 턴만 끄기로 → 원하는 항목 끄기 → 메시지 전송. 응답 받으면 자동으로 돌아온다.
한동안 안 쓸 항목 묶어서 재우기
모드를 고정 끄기로 → 검색창에 공통 이름 → 모두 끄기. 나중에 같은 검색으로 모두 켜기.

**-- Caveats --**

알고 쓰면 좋은 한계
· 보조 제외는 문자열 매칭이다. 항목 본문이 CBS 조건문 범벅이면 통째로는 못 찾고 평문 줄만 걷어낸다(✂️△). 본문이 전부 CBS면 판별 불가. 그런 항목은 고정 끄기나 이번 턴만으로.
· 리수 요청 파이프라인을 타는 요청만 본다. 메인 채팅, 루아 axLLM/LLM, 리수 내장 번역·요약은 되고, 플러그인이 API를 직접 호출하는 경우(nativeFetch)는 못 본다.
· 이번 턴만은 삽화 같은 보조 호출이 먼저 소비하면 그 뒤 "다음 메시지 보낼 때" 켜진다. 삽화만 돌리고 패널 열면 아직 1턴 OFF로 보이는 게 정상.
· 같은 요청 훅을 쓰는 다른 플러그인(로어 모니터류)은 리수가 플러그인을 동시에 띄우는 탓에 순서가 그때그때 달라서, 보조 요청에선 걷어내기 전 수치를 보여줄 수 있다. 실제 결과는 이 플러그인의 기록 패널 글자 수가 기준.
· 그룹 채팅은 캐릭터 로어북 구조가 달라 제대로 테스트 안 됐다.
